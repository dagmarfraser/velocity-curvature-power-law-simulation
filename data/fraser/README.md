# Fraser — iPad Shape Tracing (Test–Retest)

Confirmatory test–retest shape-tracing study on an iPad Pro with Apple Pencil, University of Birmingham. This dataset supersedes an earlier internal pilot cohort ("Pilot," see `data/pilot/`) — same task and software, a separate, later-recruited group of participants.

**Used in this project:** core empirical validation dataset. 48 participants recruited, 45 usable in the final analysis (3 excluded for missing sessions), ~2,830 ellipse-tracing trials.

## Redistribution

Not redistributed through this repository. Intended for future deposit via UBIRA eData (University of Birmingham's research data repository); contact for access in the meantime.

## About the data

- iPad Pro 13" (M4), Apple Pencil, 240 Hz touch sampling, via StimuliApp.
- 2 visits per participant, 3 sessions per visit, 50 trials per session (10 per shape across 5 shape templates); this project's own analysis uses the ellipse trials only.
- 10-second continuous tracing trials.
