# Pilot — iPad Shape Tracing (Retired)

An earlier internal pilot cohort for the same iPad shape-tracing task described in `data/fraser/`. **Retired and superseded by the Fraser dataset** (`data/fraser/`) — kept here for provenance only, not part of the current analysis.

**Used in this project:** none (historical/superseded). See `data/fraser/README.md` for the active dataset.

## Redistribution

Not redistributed through this repository.

## About the data

- iPad Pro 13" (M4), Apple Pencil, 240 Hz touch sampling, via StimuliApp.
- 61 participants, same task design as the Fraser dataset that replaced it.
