# Santos et al. (2022) — Multi-Sensor Human Gait Dataset

Synchronised optical motion capture and wearable IMU recordings of overground walking.

**Citation:** Santos et al. (2022). A multisensor human gait dataset captured through an optical system and inertial measurement units. *Scientific Data*, 9, 545.
**DOI:** [10.1038/s41597-022-01638-2](https://doi.org/10.1038/s41597-022-01638-2)
**Data (Figshare):** [10.6084/m9.figshare.14727231](https://doi.org/10.6084/m9.figshare.14727231)

**Used in this project:** side-project (Coherence Gap sub-project) — used to characterise how position vs acceleration measurements agree spectrally, not part of the main pre-registered pipeline comparison.

## Redistribution

Open access via Figshare (link above); not separately redistributed here.

## About the data

- Qualisys optical motion capture (42 reflective markers) and an IMU (InvenSense MPU-9250), both at 100 Hz, synchronised.
- Overground walking trials.
