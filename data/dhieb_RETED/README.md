# Dhieb RETED — Lifespan Ellipse Tracing

Continuous ellipse tracing on a graphics tablet across a lifespan sample (ages 19–85).

**Citation:** Dhieb, T., Rezzoug, N., Boubaker, H., Gorce, P., Alimi, A. M., & Fradet, L. (2022). Do individual characteristics influence the beta-elliptic modelling errors during ellipse drawing movements? *Computer Methods in Biomechanics and Biomedical Engineering*, 25(7), 783–793.
**DOI:** [10.1080/10255842.2021.1978434](https://doi.org/10.1080/10255842.2021.1978434)
**Dataset DOI (RETED, IEEE Dataport):** [10.21227/4pe3-jp45](https://doi.org/10.21227/4pe3-jp45)

**Used in this project:** core empirical validation dataset.

## Redistribution

Not permitted through this repository. Obtain directly from IEEE Dataport (link above).

## About the data

- GENIUS MousePen i608X graphics tablet, 100 Hz.
- 90 participants aged 19–85, tracing a template ellipse continuously for 60 seconds at a self-selected pace.
- One file per participant; participant demographics are included in the dataset's own supplementary file.
